# U3 實驗報告：音節拼接的自然度

日期：2026-08-23
狀態：**實驗已做，客觀部分全數通過；主觀自然度待使用者聽判。**

重跑：`python tools/say.py --experiment`，音檔輸出到 `out/audio/`。

---

## 0. 這個實驗推翻了原本的前提

PLAN.md 與 HANDOVER 假設中文發音要**錄 1300 個音節再拼接**，並把
「Ekho 音節音檔授權不明」列為最大風險 U1。

**這個前提可能是錯的。** 1980 年代的電子字典做不到那件事 —— 當年沒有記憶體
放 1300 段錄音。它們用的是**共振峰合成**：幾個共振器加一個嗡嗡作響的聲源，
全部由規則驅動。那個「機器人腔」不是妥協的產物，就是這個技術本身的聲音，
而本專案要的正好就是那個聲音。

所以實驗做成了共振峰合成器（`tools/synth/`），而不是拼接播放器。
如果聽起來可以接受：

| | 錄音拼接 | 共振峰合成 |
|---|---|---|
| 資料 | 約 2MB 音節庫（估） | **428 bytes 參數表**（實測） |
| 授權風險 | U1 未解，或自錄一個下午 | **沒有資料，就沒有授權問題** |
| 聲調 | 每個音節要錄 5 份，或事後變調 | 基頻軌跡，**免費** |
| 音節間過渡 | 拼接處會有稜角 | 共振峰連續滑行，**天生沒有接縫** |
| 涵蓋率 | 錄漏就念不出來 | 規則生成，427 個音節全有 |

## 1. RP2040 跑得動嗎

跑得動，而且餘裕大得離譜。

| | |
|---|---|
| 每個取樣可用 | 15,625 cycles（250MHz / 16kHz） |
| 實際需要 | 3 個二階共振器 + 聲源，定點約 60–80 cycles |
| **餘裕** | **約 195 倍** |
| 參數表 | 428 bytes |

取樣率取 16kHz 已經比當年的裝置（8–10kHz）寬裕。真的不夠還能降到 8kHz，
再省一半。

**注意**：這是紙上計算，不是板子上的量測。PLAN.md 的慣例是這種數字只當
數量級參考。但 195 倍的餘裕就算估錯一個數量級也還有 19 倍。

## 3. 要靠耳朵的四件事

客觀檢查驗不了自然度。以下四組是刻意做成 A/B 對照的：

| 聽 | 問題 |
|---|---|
| `01_four_tones` | 四聲 + 輕聲，同一個音節。聲調對不對，這個最準 |
| `09_sentence` | 「我是中国人，我会说中文」。整句像不像中文 |
| `03` vs `04` | 音節間要不要留 60ms 間隙 |
| `05` vs `06` | 三聲連讀變調（你好 ni2 hao3 vs ni3 hao3）值不值得做 |
| `07` vs `08` | 輕聲要不要看前字調高（桌子/椅子/本子/帽子） |
| `02_vowels` | 母音清單。母音不對的話上面全部免談 |

三組 A/B 的意義：如果聽不出差別，對應的規則就可以刪掉，程式少一塊。
**這是實驗真正的價值 —— 不只是「行不行」，而是「哪些複雜度是白花的」。**

---

## 4. 架構上的一個發現

變調（三聲連讀、不、一）與聲調曲線**分屬兩層，而且分對了**：

- **變調**是語言規則 → 轉檔期做完，存在 `.DAT` 的 `SYL_ZH`（FORMAT.md §4.2）
- **聲調曲線**是發音特徵 → 播放器即時算

實驗過程順帶驗證了這條線：`python tools/say.py 你好` 從 `CE.DAT` 讀出
轉檔期算好的音節 id，得到的結果與直接餵拼音**完全相同**。
等於順便測了整條資料路徑。

---

## 5. 已知不足

誠實列出，這是實驗不是成品：

- **沒有真人對照**。聽起來「像不像中文」只能靠主觀判斷
- **共振峰參數是查表填的，未經調校**。母音聽起來對不對是第一個要判的事
- **沒有協同發音（coarticulation）跨音節**。音節內的共振峰會滑行，
  但音節與音節之間目前是各算各的
- **沒有句調（intonation）**。整句是一串音節，沒有句子層次的音高走勢，
  這大概是 `09_sentence` 聽起來最像機器的原因
- **英文完全沒做** —— 那是 D2（SAM vs eSpeak-ng）。不過如果中文這條路成立，
  D2 的答案可能會變成「都不要，用同一個共振峰合成器」

## 6. 下一步取決於你聽到什麼

- **能接受** → U1 直接關閉（不需要錄音、沒有授權問題），
  PLAN.md 的音節庫從 2MB 降到 428 bytes，D2 也可能一併解決
- **不能接受但方向對** → 調共振峰參數、加句調、加跨音節協同發音
- **完全不能聽** → 回到錄音拼接，但 `tools/synth/prosody.py` 的聲調與時長
  規則仍然可以直接用在拼接播放器上，不是白做的
